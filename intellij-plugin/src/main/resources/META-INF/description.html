PluginFence is a runtime firewall for IntelliJ plugins.

It watches what third-party plugins actually do - files, credentials, environment variables, network destinations and process execution - enforces per-plugin permissions, correlates suspicious sequences such as "read SSH key, then open a new connection", and shows exactly how a plugin's behaviour changed after an update.

Requires the PluginFence JVM agent (-javaagent:plugin-fence-agent.jar) for enforcement.
